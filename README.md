# Hello World на C++

Простая программа на C++, которая выводит текст `Hello World` в консоль.

## Описание

Это учебный пример, демонстрирующий:
- Подключение стандартной библиотеки ввода-вывода (`#include `)
- Использование `std::cout` для вывода текста
- Базовую структуру программы на C++

## Требования

- Компилятор C++ (g++, clang++ или MSVC)
- Поддержка стандарта C++11 или новее
